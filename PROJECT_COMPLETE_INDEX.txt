📋 CONFIGURATION REQUISE

Avant de déployer, remplir .env:

```env
# JWT Security
JWT_SECRET=your-super-secret-key-min-32-chars
JWT_EXPIRY=7d

# WhatsApp (Twilio)
TWILIO_ACCOUNT_SID=ACxxx...
TWILIO_AUTH_TOKEN=xxx...
TWILIO_WHATSAPP_NUMBER=+14155238886

# Email
EMAIL_USER=your@gmail.com
EMAIL_PASSWORD=app-password

# Push Notifications
VAPID_PUBLIC_KEY=xxx
VAPID_PRIVATE_KEY=xxx

# Domaine
DOMAIN=your-domain.com
CORS_ORIGIN=https://your-domain.com
```

**Voir .env.example pour la liste complète**

💡 CONSEILS IMPORTANTS

1. SÉCURITÉ:
   - Changer JWT_SECRET avant déploiement
   - Configurer HTTPS/SSL
   - Utiliser variables d'environnement
   - Configurer CORS strictement

2. PERFORMANCE:
   - Utiliser Redis pour caching
   - Indexer les colonnes fréquentes
   - Compresser les réponses
   - Activer compression gzip

3. MONITORING:
   - Ajouter Sentry pour error tracking
   - Configurer logs centralisés
   - Mettre en place alertes
   - Monitorer la base de données

4. BACKUPS:
   - Configurer backups quotidiens
   - Tester restauration régulièrement
   - Garder plusieurs versions
   - Stocker sur cloud sécurisé
