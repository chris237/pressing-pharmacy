🚀 DÉMARRAGE RAPIDE (5 MINUTES)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ÉTAPE 1: INSTALLER NODE.JS

1. Allez sur: https://nodejs.org
2. Téléchargez la version LTS (Long Term Support)
3. Installez (cliquez Next, Next, Finish)
4. Redémarrez votre ordinateur
5. Vérifiez:
   - Ouvrez cmd/terminal
   - Tapez: node --version
   - Vous devez voir un numéro (ex: v18.17.0)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ÉTAPE 2: INSTALLER L'APPLICATION

1. Extrayez TOUS les fichiers dans un dossier
   Ex: C:\Users\Vous\pressing-app

2. Ouvrez cmd/terminal dans ce dossier:
   - Windows: Clic droit → "Ouvrir le terminal ici"
   - Mac/Linux: Right click → Terminal

3. Exécutez:
   npm install
   
   (cela va télécharger ~50 MB, attendez 2-5 minutes)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ÉTAPE 3: DÉMARRER L'APPLICATION

Tapez dans le terminal:
   npm start

Vous devez voir:
   ✅ Base de données connectée
   ✅ Tables créées avec succès
   🚀 Serveur démarré sur http://localhost:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ÉTAPE 4: OUVRIR DANS LE NAVIGATEUR

1. Ouvrez votre navigateur (Chrome, Firefox, Safari, Edge)
2. Allez à: http://localhost:3000
3. L'application devrait s'afficher! 🎉

❓ PROBLÈMES COURANTS

❌ "Cannot find module"
→ Essayez: npm install

❌ "Port 3000 already in use"
→ Essayez: PORT=3001 npm start

❌ "Rien ne s'affiche"
→ Vérifiez: http://localhost:3000 (pas https)

❌ "Erreur base de données"
→ Supprimez app.db et relancez

➡️ Voir README.md pour plus de solutions

📱 SUR TÉLÉPHONE

L'application est 100% responsive!

1. Assurez-vous que le serveur tourne (npm start)
2. Trouvez votre adresse IP:
   - Windows: cmd → ipconfig
   - Cherchez "IPv4 Address" (ex: 192.168.1.100)
3. Sur le téléphone, allez à:
   http://192.168.1.100:3000
   
(Remplacez par votre adresse IP réelle)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💾 SAUVEGARDES

Le fichier app.db contient TOUTES vos données.

Sauvegardez régulièrement:

1. Chaque jour:
   Copier app.db en backup
   
2. Chaque semaine:
   Sur disque externe ou cloud (Google Drive, Dropbox)
   
3. Restaurer une sauvegarde:
   Copier app.db.backup → app.db
   
SANS SAUVEGARDE = RISQUE DE PERTE DE DONNÉES!
